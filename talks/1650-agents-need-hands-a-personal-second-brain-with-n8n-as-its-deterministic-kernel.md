## Abstract

Agents can think, but they cannot act. Over the past months, the speaker built a personal "Second Brain" spanning 25 years of his life: 9,397 scanned documents, 3,289 notes, his antique watch business's ERP, and two fully transcribed YouTube channels — 37,554 searchable memories, visualized as a 3D galaxy and answered entirely by local models, with zero cloud and zero API fees.

n8n is the deterministic kernel of this system: an MCP Server Trigger turns eight workflows into tools any agent can call, a Switch-based router cascade decides where each question goes (66/68 reproducible routing accuracy, no LLM in the hot path), and the execution log caught every lie his agent ever told him.

In this session, the speaker will show the real workflow graphs behind the system, walk through the traps that cost him nights, nondeterministic vector search, stemming floods, invented facts, and demo the system live: the galaxy flying itself, and Telegram answering questions from his pocket.

## Takeaway

See the MCP Server Trigger pattern in action: how n8n workflows become tools an agent can call

Understand a deterministic router cascade for question-routing, with reproducible accuracy and no LLM in the hot path

Discover the traps that can derail a system like this — nondeterministic vector search, stemming floods, and invented facts

Watch a live demo of the full system: a 3D memory galaxy that navigates itself, answering questions in real time over Telegram
